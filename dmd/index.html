DMD bitmap editor

Draw in grayscale and export a bitmap. Everything stays in this browser.

Drawing

Click to paint. Click the same spot again with the same gray to erase. Drag to draw continuously. Brush size 1 edits one DMD pixel.

Examples & position

Drag anywhere on the canvas to move the whole pattern, including hand-drawn pixels. Movement stops at the edges so no pixels are lost. Center X/Y follows the move; Ctrl/Cmd+Z undoes it.

Examples replace the drawing; Undo restores it. Shapes use the selected gray on black. Size is the outer width/height; for text it is the maximum height. Half fills and stripes stay inside that square. Coordinates start at (0, 0), top left.

Cursor & view
Pointer: —

Click the canvas to place the selected cursor; drag any crosshair to move it. Add cursor creates another independent crosshair. With no cursors, your first click creates one. Arrow keys move the selected cursor one pixel; Shift moves ten. Cursors stay fixed when you drag the pattern. Only cursors checked for inclusion are exported, at 1 pixel thick.

Bitmap file

Default: DLP6500, 1920 × 1080. Export: uncompressed 24-bit BMP with identical R/G/B values, preserving every gray level. Resizing preserves the top-left overlap and fills new space black.

For grayscale in LightCrafter, use an 8-bit pattern/LUT setting. Gray values request temporal modulation; mirrors still switch between their ON and OFF angles. Apply changes with Stop → Update LUT → Start after loading.
